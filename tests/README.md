# 测试说明

## 1. 测试环境

- 操作系统：Windows
- 后端框架：Flask
- 数据库：MongoDB
- 测试方式：通过 PowerShell 的 `Invoke-RestMethod` 调用本地 HTTP API
- 服务地址：`http://127.0.0.1:5000`
- 测试数据库：`survey_system`

## 2. 已执行的测试

### 2.1 用户认证

- 创建测试用户并登录。
- 使用登录会话访问需要认证的接口。
- 通过 `/api/auth/me` 确认登录状态。

### 2.2 问卷创建与发布

- 创建问卷并检查返回的问卷 ID、标题、状态和分享码。
- 为草稿问卷添加题目。
- 发布至少包含一道题目的问卷。
- 通过分享码获取已发布问卷。

### 2.3 中文编码

- 使用 UTF-8 编码发送 JSON 请求。
- 检查问卷标题、描述、题目和选项中的中文是否正确保存和返回。

### 2.4 答案校验

- 数值题提交超过最大值的答案，接口返回错误。
- 多选题提交超过最大选择数量的答案，接口返回错误。
- 必填文本题提交空答案，接口返回错误。

### 2.5 答卷提交与统计

- 成功提交包含单选、多选、文本和数值题的答卷。
- 查询统计接口，检查答卷总数、单选选项计数、多选选项计数、文本答案和数值平均值。

### 2.6 单选题条件跳转

- 设置单选题选中指定选项时跳转到后续题目。
- 提交符合跳转路径的答卷，接口接受提交。
- 故意提交被跳过题目的答案，接口返回错误。

### 2.7 数字题条件跳转

测试问卷：`数字题条件跳转测试`

分享码：`uF51_g71K8E`

规则：第一题答案大于等于 3 时跳转到第三题，跳过第二题。

- 用例 A：第一题答案为 3，提交第一题和第三题，不提交第二题。实际结果：答卷提交成功。
- 用例 B：第一题答案为 2，提交全部三道题。实际结果：答卷提交成功。

## 3. 测试执行方式

1. 启动 MongoDB 服务。
2. 在项目虚拟环境中启动 Flask 服务。
3. 使用已登录的 PowerShell Web 会话调用 API。
4. 对比接口返回结果与预期结果。
5. 记录成功响应、错误响应和答卷 ID。
