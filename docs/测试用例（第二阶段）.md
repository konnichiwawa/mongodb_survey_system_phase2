# 测试用例（第二阶段）

## 一、测试目的

本测试用于验证基于 MongoDB 的问卷系统在第一阶段功能基础上进行需求扩展后的主要功能是否正常。测试范围包括第二阶段新增的题目复用、题目分享、题目修改与版本管理、题目使用情况查询、题库管理和跨问卷单题统计等功能。

本项目以 API 自动化测试为主，使用 `pytest` 执行 `tests/test_api.py` 中的测试用例。测试通过接口响应、业务结果及数据变化验证系统行为。

## 二、测试环境

| 项目 | 配置 |
|---|---|
| 操作系统 | Windows |
| Python 版本 | Python 3.14.7 |
| 测试框架 | pytest 9.1.1 |
| 数据库 | MongoDB 8.3.11 |
| Python 运行环境 | 项目虚拟环境 `.venv` |
| 自动化测试文件 | `tests/test_api.py` |
| 测试数据库 | `survey_system_test` |
| 测试方式 | API 自动化测试 |

## 三、测试方法与范围

本项目采用 API 自动化测试方式，通过测试客户端调用后端接口，检查响应状态、返回数据、业务校验结果以及必要的数据关联关系。对题目版本、题目分享和题库等涉及多步操作的功能，按用例步骤依次执行，检查操作前后的数据变化。

测试范围如下：

1. 保存和复用常用题目。
2. 分享题目给其他用户。
3. 修改题目时保护已有问卷内容。
4. 查询题目修改历史。
5. 恢复题目旧版本。
6. 同一题目的不同版本共存。
7. 查询题目被哪些问卷使用。
8. 题库相关操作。
9. 按逻辑题目标识跨问卷汇总统计结果。

> 测试记录说明：已确认的自动化回归结果为完整测试 40 项通过，单题统计筛选测试 4 项通过。全量测试结果能够证明测试套件中的断言均通过，因此，以下“实际输出”以目前可确认的测试记录为依据。

## 五、自动化测试执行方法

在项目根目录打开 PowerShell，启用项目虚拟环境后执行：

```powershell
python -m pytest tests/test_api.py -v
```

如需运行全部测试，可以执行：

```powershell
python -m pytest -v
```

仅运行跨问卷单题统计相关测试，可以执行：

```powershell
python -m pytest tests/test_api.py -v -k "question_stats"
```
